# Первый автономный агент погоды

База: Ainkrad F2, `5019f6eb48dca6a62adf5e9329360e132b203208`.

Изменён только Ainkrad. Iskorka — независимый проект; его код и развитие не входят в эту работу.

## Реализовано

- Исходная модель WeatherV21 сохранена в WeatherModelV21 с теми же формулами, сезонностью, ключами случайности и коэффициентами. Старое имя `worldWeatherV21` сохранено для всех потребителей.
- Погоду действительно рассчитывает WeatherSystemAgent. Его вход ограничен идентификатором мира, эпохой, погодной изменчивостью и мировым временем. Агент не получает жителей, мысли, память, отношения, общий WorldState, мировой RNG или хранилище.
- Агент зарегистрирован в существующем SystemAgentOrchestrator на стороне мира. Нормальная работа не требует экземпляра Cardinal.
- Поддержаны start/stop/restrict/restore/retire. Остановка или сбой управляемого исполнителя включают исходную автономную модель: климат не замирает вместе с исполнителем. Неизвестные права отклоняются.
- Контрольный метод WorldEngine проверяет ревизию и выполняется в существующей атомарной транзакции. Повтор одной команды не выполняется повторно; ошибка записи не оставляет частично изменённый мир.
- `weatherSystem` добавляется к сохранению без удаления существующих полей. Сохраняется одно текущее состояние; история погоды на каждом кадре не накапливается.
- Все прежние потребители — жители, сон, тело, лодки, карта — обращаются к агенту через совместимый интерфейс. Текущие правила их поведения сохранены.
- В интерфейсе добавлено раскрываемое поле «Системы мира» со статусом погодного агента.

## Проверки

- 42 эталонных результата получены из исходной модели принятого коммита до изменения; новый агент совпадает с ними точно.
- Проверены отсутствие дирижёра, остановка/восстановление, ограничения прав, исключение исполнителя, некорректный результат и автономный резерв.
- Проверены настоящий WorldEngine/WorldStore, сохранение, загрузка, повтор команды и добавление состояния в старое сохранение без изменения жителей и отношений.
- Целевой запуск: 16/16 тестов, включая существующие проверки лодочной навигации и границ системных агентов.
- Итог общего набора тестов и сборки записывается в `WEATHER_AGENT_VALIDATION.txt` в корне пакета.

## Граница первого этапа

Это первый исполнитель и его подключение к миру. Автоматический выбор ремонта самим CardinalCore, замена реализации с миграцией, отдельный процесс Кардинала, кнопки отключения всего Кардинала и парный экран ON/OFF здесь не объявляются готовыми. Погодный агент уже не зависит от них и может быть использован на следующем этапе.

Перехватываются синхронные исключения и некорректные результаты. Прерывание бесконечного цикла требует отдельного Worker; этот вариант изоляции пока не добавлен. Остановка погодного исполнителя не означает отключение всей системы Кардинала.

Для ON/OFF-сравнения исходная модель и резерв одинаковы. Контрольный мир не ослаблен. Новая погода не расходует мировой RNG, не уменьшает возможности жителей и не меняет частоту их решений.

В архиве находятся локально проверенные исходники. Новый коммит не отправлялся в GitHub и не проходил удалённый CI. Это не публикация на Vercel.
