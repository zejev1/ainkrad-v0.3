# Cardinal, World и Gateway

Направление проекта, уточнённое владельцем 11 сентября 2026 года.

Cardinal — самостоятельная развиваемая система. World — автономная среда для
наблюдений и проверки гипотез. Gateway проверяет допустимость воздействия.
Обычная жизнь жителей, обучение и история поколений принадлежат World.

## Что закреплено в FIX3

- Общие форматы сообщений и допустимых воздействий находятся в
  `src/core/WorldContracts.ts`. WorldEngine не импортирует внутренние типы Cardinal
  и транспорт runtime. Старые импорты потребителей сохранены через типовые aliases.
- Метка `source: cardinal` обозначает происхождение сообщения, а не полномочия.
  Проверки Gateway остаются обязательными; права не растут вместе с опытом.
- Частота рисования карты отделена от канонических шагов мира. Ограничение
  количества видимых значков не удаляет людей, знания или события из симуляции.
- Строительство по-прежнему требует реального труда, решения жителя и материалов.
  Исправление координат существующего города не создаёт новые дома и не меняет
  семьи, знания, убеждения, возраст, календарь или генератор случайных чисел.
- Существующие проверки World без Cardinal, режимов OFF/OBSERVER, protected
  personhood, Gateway и сохранения опыта остаются частью выпускного аудита.

## Честная граница текущей защиты

Нынешний автономный браузерный пакет содержит реализацию World, Cardinal и Gateway
в worker. Она доступна получателю JavaScript. Разделение файлов, минификация и
отсутствие source map не делают алгоритмы закрытыми. В FIX3 не добавлены клиентские
«секреты», новые серверные зависимости, лицензирование, смена видимости GitHub или
заявления о невозможности копирования.

Git-история и SHA256 файлов пакета позволяют связать конкретное состояние с
исходной ревизией. Они сами по себе не доказывают уникальность идеи и не запрещают
копирование. Для настоящего скрытия закрытая реализация должна не входить в
публичный репозиторий и клиентскую сборку.

## Следующий отдельный этап

1. Публичный World адаптер передаёт выбранные наблюдения; закрытая реализация
   Cardinal возвращает предложение, а Gateway отдельно разрешает или отклоняет
   воздействие. Отказ/задержка Cardinal не останавливает World.
2. При серверной защите состояние, которое нужно защищать от владельца клиента,
   требует доверенной стороны. Локальные проверки в чужом браузере можно изменить.
   Скрытие внутренних деталей Gateway не заменяет разграничения полномочий.
3. Внешний AI в теле одного NPC получает только доступные этому жителю восприятия,
   память и известные места. Ни полная карта, ни скрытые состояния других умов
   в этот контракт не входят. Подключение внешних AI в FIX3 не выполняется.
4. Наблюдение должно различать естественные потери вследствие решений жителей и
   технически невозможное состояние. Изменение политики Cardinal по этому критерию
   требует отдельного разбора причин и проверки истории; FIX3 не выдаёт текущие
   эвристики за уже реализованное понимание причин катастроф.

Обсуждение Alicization-Town используется как контекст направления. Его код,
графика, сетевые протоколы и внешние зависимости в этот пакет не переносились.
