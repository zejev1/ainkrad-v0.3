Это модель гребной лодки для берегов, рек и озёр, с ограничением водного участка
до 4 км по прямой / 6 км по курсу и вместимостью до двух взрослых. Масса груза
явно переводится из товарных единиц (20 кг на единицу). Типы крупных судов,
парусная аэродинамика и океанские экспедиции здесь не реализованы; ограничения
указаны прямо, а не скрыты за названием предмета.

## База и Push

База проверяется перед упаковкой по текущему `origin/main`. Новый Git-каталог
создаётся отдельно, все refs указывают на эту базу, remote — официальный URL
репозитория. Собственных коммитов и Push со стороны помощника нет. Исходники
остаются изменениями для пользовательского Commit в SPCK, корень ZIP плоский.

Правила GitHub на момент проверки запрещали только удаление и non-fast-forward.
Сообщение телефона `refs/heads/main: failed` не содержало причину отказа.
Подробный журнал отказа недоступен подключению GitHub (403). Поэтому успешность
Push с телефона не выдаётся за выполненную проверку и защита не отключается.
Архив предназначен для импорта отдельным проектом, без наложения на старый Git.

## Ориентир мира

Сначала развивается самостоятельный мир: личный опыт, выбор, физические
ограничения, причинные последствия и смерть; работа над возможностями Cardinal
не должна подменять развитие агентов. В этой правке Cardinal/Gateway не получают
новых полномочий и не выбирают людям занятия или направления движения.

Сверены официальные описания [Alice, эпизод 22](https://sao-alicization.com/story/?id=ep22)
и [New World, эпизод 23](https://sao-alicization.com/story/?id=ep23): Алиса представлена
как самостоятельный искусственный интеллект и действует вне непосредственных
указаний исследователей. Это художественный ориентир. Само наличие потребностей,
памяти и выбора в нашей модели не доказывает человеческое сознание; такой
эквивалентности данный выпуск не заявляет. Все серии целиком заново не просмотрены.
