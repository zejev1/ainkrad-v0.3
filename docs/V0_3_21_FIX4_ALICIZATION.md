# Ускорение Ainkrad и Alicization

Проверка 11 сентября 2026 года: официальные описания 24 серий Alicization и 23 серий War of Underworld на сайте Aniplex. Это сверка доступных синопсисов всего сериала, а не заявление о просмотре всех эпизодов или проверке каждого диалога.

## Что подтверждают источники

- [Alicization, серия 6: Project Alicization](https://sao-alicization.com/1st/story/06.html): внешний исследовательский комплекс Rath и Soul Translator.
- [Alicization, серия 7: Swordcraft Academy](https://sao-alicization.com/1st/story/07.html): герои прожили два года после ухода из деревни и продолжают обучение.
- [War of Underworld, серия 1](https://sao-alicization.com/story/?id=ep1): после битвы прошло шесть месяцев внутренней жизни.
- [War of Underworld, серия 20](https://sao-alicization.com/story/?id=ep20): начало предельного ускорения означает для оставшегося внутри героя следующие 200 лет в Underworld.
- [War of Underworld, серия 21](https://sao-alicization.com/story/?id=ep21): Хига и Кикуока пытаются отключить предельное ускорение снаружи через оборудование STL.
- [Полный официальный список первой части](https://sao-alicization.com/1st/story/) и [второй части](https://sao-alicization.com/story/) использованы для проверки остальных эпизодов. Основная масса их синопсисов посвящена событиям и персонажам, а не параметрам ускорения.

Официальные краткие описания не дают полной таблицы FLA для всех сцен. Численные утверждения о коэффициентах, не подтверждённые этими материалами, не становятся требованиями к программе.

## Перенос принципа в Ainkrad

Ниже — инженерные выводы для проекта на основании этой модели времени.

| Принцип | Реализация Ainkrad |
| --- | --- |
| У мира собственное прожитое время | Календарь продвигается только после расчёта событий; биология, знания, семьи и движение пользуются тем же временем. |
| Ускорение задаётся извне | Выбранная скорость проходит через независимый внешний Gateway. |
| Снижение ускорения меняет дальнейший ход времени | Команда применяется после текущего сохраняемого пакета. Непросчитанная очередь может быть остановлена; прошлое остаётся. |
| Внутренние годы имеют последствия | Каждый существующий смысловой шаг выполняется. Чтение, обучение, рождения и смерти не заменяются прибавлением числа лет. |
| Внешний наблюдатель и внутренний мир имеют разные темпы | Экран обновляется реже, чем выполняются шаги симуляции; измеренная скорость показана отдельно от цели. |

FLA — отношение скоростей часов: внутреннее время = внешнее время × коэффициент.
При 365 днях в игровом году режим «1 минута = 1 год» соответствует ×525600, «50 лет» — ×26280000, «100 лет» — ×52560000. Это расчёт из единиц Ainkrad, а не числа, приписанные аниме.

Компьютер из художественного произведения не задаёт производительность браузера телефона. Если устройство не успевает, Ainkrad показывает реально достигнутый темп и ограничивает очередь. Он не создаёт фиктивно прожитые годы.

Закрытая вкладка по умолчанию учитывает обычное время. Сохранение ускоренного фонового хода включается явно и требует последующего расчёта. Это открытое продуктовое решение для локальной браузерной симуляции; его нельзя выдавать за устройство серверного Underworld из сериала.
