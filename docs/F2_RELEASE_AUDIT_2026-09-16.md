## Performance / continuity evidence

No population-based action suppression was reintroduced.

A matched 5-year sample on the same seed/host showed the pre-final F2 checkpoint at ~8.80 s wall time and the current candidate at ~7.79 s in a later run; both produced the same macro outcome for that seed (4 births, 34 living humans, 3 settlements). Absolute timings are host/JIT dependent; this is evidence of no obvious regression, not a benchmark guarantee.

A separate 20-year current-candidate run completed in ~81.6 s wall time. At year 20 it had 131 living residents, 42 births, 1 death, 199 places, 8 settlements and 170 routes. Year-20 work was ~7.5 s; the slowest canonical quantum observed in that run was ~331 ms. The cost rises as the world physically grows, but the run did not require reducing Spark decisions or deleting history.

5-year process snapshot in a separate run: ~280.6 MiB RSS for the whole Node process (not an Android-browser measurement).
